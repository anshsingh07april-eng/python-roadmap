# Python Practice

My daily Python practice for the roadmap running from November 2026 to February 2027. The goal is to build strong Python fundamentals, improve problem-solving, and move toward Data Analysis and AI/ML.

## Folder structure

- `day01/` - Basics: input and output, type conversion, operators, if-else, and simple loops.
- `day02/` - Strings and conditions: safe calculator, time converter, interest calculator, palindrome, leap year, triangle checker, report card, password strength checker, and number tools.
- `day03/` - Lists, dictionaries and functions: list statistics, removing duplicates, mutability, word frequency, two-sum, anagrams, student database, matrix basics, list rotation, balanced brackets, and longest unique substring.

## How to run

1. Install Python 3.
2. Open a terminal inside a day folder, for example `day01`.
3. Run a program with `python Q1.py` (or `python3 Q1.py`).

## Daily routine

- Learn the concept and type every example myself.
- Solve problems without copying.
- Fix errors and note what I learned.
- Commit the work to GitHub.
